¿Cómo saber si mis datos fueron filtrados?

¿Qué es una filtración de datos?

Una filtración ocurre cuando información confidencial — como usuarios, contraseñas o correos electrónicos — queda expuesta en internet sin autorización. Esto puede pasar por un ataque a un sitio web, un malware que roba credenciales del navegador, o una base de datos mal configurada.

¿Qué tipo de datos se filtran?

Las filtraciones más comunes incluyen:

  • Credenciales de acceso: combinaciones de usuario y contraseña de sitios web, correo corporativo, paneles de administración.
  • Datos de contacto: correos electrónicos, números de teléfono, direcciones.
  • Datos de navegación: cookies de sesión, tokens de acceso, historial de sitios visitados.

¿Por qué es grave para una empresa?

Acceso no autorizado

Si las credenciales de un empleado están filtradas, un atacante puede acceder a sistemas internos, correo corporativo o paneles de administración.

Reutilización de contraseñas

La mayoría de las personas usa la misma contraseña en varios servicios. Una credencial filtrada de un sitio externo puede abrir la puerta al correo o sistema de tu empresa.

Sanciones legales

La normativa chilena exige a las organizaciones proteger los datos personales que manejan y notificar incidentes de seguridad. No detectar una filtración puede significar multas.

¿Qué hacer si encuentro datos filtrados?

  1. Cambiar las contraseñas afectadas de inmediato, tanto en el servicio filtrado como en cualquier otro donde se haya reutilizado.
  2. Activar autenticación de dos factores (2FA) en todos los servicios que lo permitan.
  3. Revisar accesos recientes a las cuentas comprometidas para detectar actividad sospechosa.
  4. Notificar internamente al equipo de TI o seguridad de la organización.
  5. Monitorear continuamente para detectar nuevas filtraciones a tiempo.

¿Cómo prevenir futuras filtraciones?

  • Usar contraseñas únicas para cada servicio (un gestor de contraseñas ayuda).
  • No ingresar credenciales en sitios sospechosos o enlaces desconocidos.
  • Mantener actualizado el software y el antivirus.
  • Capacitar a los empleados sobre phishing y buenas prácticas de seguridad.
  • Contratar un servicio de monitoreo como Datalert para recibir alertas automáticas.
